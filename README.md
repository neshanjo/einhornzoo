# 🦄 Einhornzoo

Ein kleines Einhorn-Simulationsspiel für den Browser, gebaut mit [three.js](https://threejs.org/).

**▶️ Jetzt spielen: <https://neshanjo.github.io/einhornzoo/>**

> Dieses Projekt wurde als Demo für **Claude Fable 5.2** erzeugt – der gesamte Code stammt aus einer Sitzung mit Claude Code.

## Was man machen kann

- **Einhörner erschaffen** – im Editor Fell, Mähne, Horn, Augen, Frisur, Muster, Flügel und Größe wählen oder ein Zufalls-Einhorn würfeln.
- **Füttern** – Äpfel, Karotten, Heu oder Regenbogenkuchen auslegen oder direkt verfüttern.
- **Futtertröge aufstellen** – hungrige Einhörner bedienen sich selbst; leere Tröge per Klick auffüllen.
- **Accessoires anlegen** – Krone, Zauberhut, Blumenkranz, Schal, Glöckchen, Satteldecke, Schleife, Sonnenbrille, Glitzerstaub.
- **Interagieren** – streicheln, zaubern lassen, irgendwohin schicken. Einhörner schließen Freundschaften und bekommen manchmal Fohlen.
- **Dekorieren** – Blumen, Bäume, Riesenpilze und Laternen pflanzen.
- **Erkunden** – Wiesen, Wald und vier Teiche, Tag-Nacht-Wechsel und eine Minikarte mit allen Einhörnern.

Der Spielstand wird automatisch im Browser gespeichert.

## Steuerung

| Aktion | Eingabe |
| --- | --- |
| Kamera drehen | Ziehen |
| Zoomen | Mausrad |
| Kamera bewegen | Rechtsklick-Ziehen oder WASD |
| Zu einem Ort springen | Klick auf die Minikarte |
| Abbrechen / Auswahl aufheben | Esc |

## Lokal starten

Das Spiel besteht aus einer einzigen Datei. `index.html` im Browser öffnen genügt; three.js und die Schrift werden von einem CDN geladen, daher ist eine Internetverbindung nötig.
